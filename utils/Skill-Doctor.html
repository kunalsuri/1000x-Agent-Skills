📐 Agent Skills Specification Reference (agentskills.io)

Every skill in this repository follows the open standard compatible with Claude Code, Google Antigravity, Cursor, OpenAI Codex, and Copilot.

Field Requirement Description & Best Practice
name Required Must be lowercase alphanumeric and hyphens only (^[a-z0-9-]+$), ≤64 chars. Must exactly match directory name.
description Required ≤1024 characters. Must state both WHAT the skill does and WHEN to trigger (e.g., "Use when..."). Critical for auto-routing.
version Attestation Semantic versioning (1.0.0). Incremented upon workflow changes.
compatibility Optional List of tested agent platforms: [claude-code, antigravity, cursor, codex].
allowed-tools Optional Tools this skill restricts or prefers to use (e.g., [view_file, run_command]).
Progressive Loading Architecture Agent loads frontmatter at startup (~100 tokens), then only loads full body when triggered. Keep body ≤500 lines.
