# To verify and use the following Online Agent Skills:

## Claude Code Setup Plugin
Its an official marketplace plugin from Claude. It looks at your codebase and recommends hooks, skills, MCP servers and subagents to set up. In an interactive claude terminal, run these two commands:

>    /plugin marketplace add anthropics/claude-plugins-official


>    /plugin install claude-code-setup@claude-plugins-official
